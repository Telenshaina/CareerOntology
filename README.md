# Bridging Knowledge and Choice: An Ontology-Based Approach to Student Program Selection in CICS

## Overview

This study introduces an ontology-based decision-support system designed to assist students at New Era University's College of Informatics and Computing Studies (CICS) in making informed academic program selections. Addressing common challenges such as program mismatches and academic delays, the system leverages the Web Ontology Language (OWL) to map relationships between student interests, skills, academic programs (BS Computer Science, BS Information Technology, BS Entertainment and Multimedia Computing with Specialization in Digital Animation Technology, BS Entertainment and Multimedia Computing with Specialization in Game Development, and BS Information Systems), and career pathways. By integrating rule-based reasoning with ontology-driven recommendations, the system provides structured, personalized guidance to enhance student satisfaction and retention.

## Abstract

Choosing an academic program is a critical decision that impacts a student's academic journey and future career. At New Era University’s College of Informatics and Computing Studies (CICS), students often struggle with program selection, leading to mismatches and academic delays. This study explores the development of an ontology-based decision-support system to improve program selection by providing structured, personalized recommendations.

Using the Web Ontology Language (OWL), the system maps relationships among student interests, skills, academic programs, and career pathways. It integrates rule-based reasoning with ontology-driven recommendations to identify suitable academic programs based on logical mappings and semantic relationships. The prototype was tested with 22 participants, analyzing interest trends across various academic domains. Findings revealed strong correlations between student preferences and relevant degree programs, demonstrating the system's ability to enhance transparency and personalization in academic advising.

This research highlights the value of AI-driven knowledge models in improving student satisfaction and retention, offering a scalable solution for academic guidance. Future enhancements include expanding the dataset, refining the ontology, and integrating adaptive learning mechanisms for evolving recommendations.

## Keywords

Ontology-based, recommender system, academic advising, education, semantic web rule language, rule-base inference


The process of selecting a college program significantly influences a student's academic and career trajectory. Students at New Era University's CICS often face difficulties in distinguishing between various degree programs, leading to potential mismatches, course changes, and academic setbacks. Existing initiatives like Career Expo Day offer limited, non-personalized guidance. This research addresses the need for a structured, adaptive, and student-centered decision-support system by developing an ontology-based approach.

Leveraging recent advancements in ontology-based systems, which formally represent knowledge and enable semantic reasoning, this study aims to create a personalized academic advising tool. Inspired by systems like EduCOR Ontology and recommendations for data-driven academic advising strategies, this project seeks to improve transparency, accessibility, and personalization in academic guidance within CICS. The ultimate goal is to enhance student satisfaction, retention, and academic performance, with potential broader applications in educational career guidance.
